# 用例及覆盖

本阶段没有新增测试框架或修改生产代码，复验既有 `frontend/tests/console.test.ts` 的 `10` 条行为测试，并在真实浏览器补充模型测试不能证明的路径。

| 层级 | 覆盖 |
|---|---|
| `node:test` | 本人/来源鉴权分离、写请求不重试、历史合并、安全链接、轮次事实关联、旧连接/旧详情响应、分页跨定时器、卡片变化、旧活动精确终态、同事实最后投影 |
| 浏览器与真实中台 | 错密钥、真实数据、问题回答与续接、原始回答追溯、结案、停止请求与测试接单确认、来源事件/去重、筛选空结果、自动刷新、故障陈旧与恢复、断开草稿清理、窄屏、文本安全、内存凭据 |
| 环境限制 | 根快速测试的既存 `Windows` 失败单列于报告；不冒充通过 |

复现：先运行 `npm --prefix frontend run fixture`，从其输出取得临时地址与凭据；开发服务将固定代理指向该地址。用真实浏览器通过页面操作，测试接单身份只通过原协议领取和交回执，不运行实际业务命令。不要连接生产服务；结束后清理临时目录与进程。截图位于本阶段目录，临时密钥不入报告。
