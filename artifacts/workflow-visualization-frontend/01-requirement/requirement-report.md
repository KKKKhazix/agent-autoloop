# 实时流程操作台需求

## 上下文分析

项目只有后端、命令行与卡片表单，用户难以看清整个循环。已有 `GET /v1/state` 提供来源、规则、执行程序、通道、卡片、轮次、未分派事件及用量；`GET /v1/runs/:id/why` 提供轮次关联事实；`GET /v1/stream` 提供可续传的事实流。本人密钥允许查询、回答、结案和停止，发送事件需要单独来源密钥。没有现成的前端、浏览器跨域支持；客户端需处理同源代理及带鉴权头的流请求。

## 澄清问答及收敛

- 用户原始要求：使用 `devflow-codex` 和 `vue-coding-standards`，在本仓库创建可视化整个流程的前端项目。
- 问：只读看板、实时操作台，还是示例演示？用户回答 `2`，选择实时操作台。
- 主线程展示首版设计：整体流程图、详情侧栏、真实状态更新、回答卡片、结案、停止任务、配置来源密钥后发送事件；独立 `frontend/`，使用 `Vue 3` 与 `TypeScript`，依赖独立管理，复用现有接口。替代为传统列表后台，推荐流程图配详情。
- 主线程说明不包含拖拽编排与规则编辑，用户明确回复“确认”。需求及产品设计已获批准，无需重复询问。

## 本批纳入范围

- 在仓库建立独立的 `frontend/` 客户端包，使用 `Vue 3`、`TypeScript`、组合式 `API`、`script setup`，遵守用户指定规范。
- 中文流程总览：来源 → 规则 → 事项 → 执行 → 回执 → 卡片/回答 → 继续执行。用状态、数量与可点击关系说明真实进展。
- 真实状态与轮次列表，可筛选、选择、分页追踪历史，侧栏查看关联事件、执行、回执、卡片和回答时间线。
- 实时更新和明确的连接状态；首次连接、断线、鉴权失败、空数据、读取失败和操作失败有可理解的反馈，保留已读数据时明确标注陈旧。
- 本人操作：回答问题卡片、结案、停止执行，操作进行时防止重复提交，更新后的状态与后端一致；停止与结案有明确的目标及确认交互。
- 发送事件表单使用单独的来源凭据；未配置时说明原因，不能冒用本人凭据。
- 可运行的开发、构建、预览或静态托管及代理路径，凭据不写入源码、网址和构建产物；默认不持久化到磁盘。
- 桌面清晰呈现，窄屏可查看及完成关键操作，语义化按钮、键盘可操作、状态不只靠颜色。
- 必要的行为测试、真实浏览器验收、使用说明；同步协议、架构图、两份 `README`、`INSTALL`、正式 `SKILL`、`SECURITY` 中与本次边界冲突的约定。

## 仓库边界决策

用户明确要求前端在本项目内，本次授权调整“总览客户端不进本仓库”这一范围约定。前端仍是经协议连接的独立客户端；不让内核认识前端或产品，不将前端依赖加入根 `package.json`，不将页面服务耦合到中台，不新增调度体系。保留 `/v1` 协议和旧插件兼容。修改维护说明时只调整必要条目。

## 排除范围

不做拖拽编排、规则编辑、模型路由、多租户、插件市场、独立用户系统或替代中台调度。不默认连接现有在线应用、发送真实业务事件/消息或运行真实交付脚本。不在本次任务默认提交、推送、合并或发布；交付本地可运行并经验证的改动与工作流产物。

## 成功标准

- 按文档可独立安装、启动、构建前端，根后端保持零运行时依赖。
- 对临时真实后端，通过页面看到事件进入、轮次状态、执行回执、提问卡片及回答后的继续执行；详情可解释选中轮次。
- 回答、结案、停止和独立来源发送事件均走现有真实接口，权限错配时明确拒绝；重复点击不能重复执行业务。
- 实时事实发生后页面更新；断线与错误可见，重新连接不会混用旧连接或旧轮次数据。
- 必要行为测试先失败后实现；前端类型检查、构建及适当测试通过，根项目 `npm run test:quick`、`npm run typecheck`、`npm run format:check` 通过（若环境或既存问题阻止则提供证据并准确记录）。不因本次修改而扩大模拟或变异框架。
- 完成独立代码审查及浏览器桌面/窄屏验收，记录真实执行证据；不得用假数据冒充成功连接。

## 风险及待落实事项

- 本人凭据有写权限，连接界面须清楚标识；代理只转发固定后端，避免任意目标代理、凭据泄漏或浏览器被动写操作。
- `EventSource` 不支持自定义鉴权头，可选使用 `fetch` 流读取并正确清理；断线恢复及刷新方式由方案阶段结合现有接口定下。
- 状态分页、时间线结构和实际卡片操作端点必须从协议与实现核实，不凭猜测实现。
- 根纯净性测试禁止根 `web/` 和运行时依赖，使用独立 `frontend/`；文档及维护约定应同步承认客户端。
- 当前运行环境为 `Windows`，项目测试可能包含类 `Unix` 命令；验证阶段分清环境限制与回归。

无阻塞产品问题；技术选型和实现细节交由后续阶段在上述已确认范围内自主完成。
